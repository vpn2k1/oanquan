# Đa ngôn ngữ (vi + en)

```
tool/gen_arb.py  (nguồn duy nhất: key → (vi, en))
   │  python3 tool/gen_arb.py
   ├──► lib/l10n/app_vi.arb, app_en.arb
   └──► lib/l10n/strings.dart            (lớp Strings tĩnh)
            │  flutter gen-l10n
            └──► lib/l10n/app_localizations*.dart
```

Trong `lib/l10n/`, chỉ `l10n.dart` và `strings_scope.dart` viết tay.

- Thêm/sửa câu: sửa `S` trong `tool/gen_arb.py`, chạy
  `python3 tool/gen_arb.py && flutter gen-l10n`, dùng `Strings.key` /
  `Strings.key(arg)`. Biến viết `{tên}`, không nối chuỗi trong UI.
- Tên hiển thị enum (`AiLevel`, `Achievement`, `FolkStyle.id`): dict `LEVELS`,
  `ACHIEVEMENTS`, `STYLES` trong script + nhánh `switch` trong
  `L10nLabels` (`lib/l10n/l10n.dart`); `HELPERS` bọc chúng vào `Strings`.
- Ngôn ngữ chọn trong Cài đặt (`AppLanguage`, lưu `settings.language`).
  `StringsScope` trong `MaterialApp.builder` nạp `Strings` mới và vẽ lại cả cây,
  giữ nguyên trạng thái màn hình.
- Thêm ngôn ngữ: đổi giá trị trong script thành bộ 3, thêm vòng ghi ARB, thêm
  giá trị vào `AppLanguage`.
- Ngôn ngữ mặc định (vi) ở 3 chỗ phải khớp: `template-arb-file`, giá trị khởi
  tạo trong `Strings`, `orElse` của `AppLanguage.byCode`.
- Test: `test/l10n/l10n_test.dart` (đổi ngôn ngữ, tiếng Anh trên máy hẹp).
